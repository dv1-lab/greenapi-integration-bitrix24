# task-tracker — техническая документация

Группа «🛠 Тех. поддержка Первый Беговой» — лёгкий трекер технических задач
компании прямо в Telegram.

**Это отдельный самостоятельный сервис** — репозиторий `dv1-lab/task-tracker`,
свой Telegram-бот `@tasktrackerdv_bot`. К клиентскому коннектору отношения не
имеет (внешние клиенты сюда не пишут). До 2026-05-20 жил внутри wa-tg-bridge —
вынесен в отдельный сервис.

Общая документация — [`SOCIAL_CONNECTOR.md`](./SOCIAL_CONNECTOR.md),
[`ARCHITECTURE.md`](./ARCHITECTURE.md). Деплой и детали — в README репозитория
`dv1-lab/task-tracker`.

Последнее обновление: 2026-05-20.

---

## 1. Модель

- Telegram forum-группа. **Каждая задача / техвопрос = отдельная тема (topic).**
- Три статуса: **📝 open** (никто не взял) → **✋ in_progress** (в работе) →
  **✅ done** (выполнено).
- Бот ведёт авто-обновляемую «Доску задач» со списком открытых.

---

## 2. Команды

### Создать задачу (в любом месте группы)

| Команда | Действие |
|---|---|
| `/n <название>` или `/new <название>` | создать новую тему-задачу (📝 open); бот публикует первое сообщение. Поддержан текст после переноса строки и `/n` в подписи к фото/файлу |

### Внутри темы задачи

| Команда | Действие |
|---|---|
| `/t` `/take` | взять в работу → ✋ |
| `/d` `/done` | выполнено → ✅ |
| `/reopen` `/back` | вернуть в работу → ✋ |
| `/r` `/rename` | переименовать тему (статус-emoji сохраняется) |
| `/f` `/free` | освободить (вернуть в open без исполнителя) |
| `/nnn` `/note` | внутренняя пометка |
| `/board_setup` `/board` | в отдельной теме-«доске» — опубликовать и закрепить авто-список задач |
| `/help` `/start` | справка |

**Авто-reopen:** сообщение в теме со статусом ✅ → задача снова ✋.

## 3. Сервис

| Параметр | Значение |
|---|---|
| Репозиторий | `dv1-lab/task-tracker` |
| Стек | Python + aiogram (polling), SQLite |
| Бот | `@tasktrackerdv_bot` |
| Деплой | my-server, systemd `task-tracker`, `/home/dv/task-tracker/` |
| Конфиг | `.env`: `BOT_TOKEN`, `GROUP_CHAT_ID`, `DB_PATH`, опц. `ADMIN_CHAT_ID` |
| Данные | SQLite `data/task-tracker.sqlite` — таблицы `internal_tasks` / `internal_topics` / `internal_board` |
| Бэкап | `.env` + `data/` в `server-ubuntu-setup/backup.sh` |

Запуск: `systemctl {status,restart} task-tracker`, логи —
`journalctl -u task-tracker`.

---

## 4. История

До 2026-05-20 трекер был функцией wa-tg-bridge (тот же бот
`1begovoyconnectbot`, таблицы в `bridge.sqlite`). Вынесен в отдельный сервис:
новый бот `@tasktrackerdv_bot`, данные мигрированы скриптом
`scripts/migrate_from_bridge.py`. В wa-tg-bridge группа техзадач отключена
(убрана из env `TG_INTERNAL_GROUPS`) — код трекера там остался дормантным,
может быть вычищен отдельно.

---

## 5. Правила (из встроенной справки бота)

- Не удалять чужие сообщения вручную; `/d` действует только на свои.
- Решённые задачи помечать `/r ✅ название` — видно в списке тем.
