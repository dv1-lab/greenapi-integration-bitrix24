# Внутренний task-tracker — техническая документация

Группа «🛠 Тех. поддержка Первый Беговой» — лёгкий трекер технических задач
компании прямо в Telegram. Реализован внутри **wa-tg-bridge** (тот же бот,
`1begovoyconnectbot` / `@begovoyconnect_bot`).

Это **отдельная функция бриджа, не часть клиентского коннектора** — внешние
клиенты сюда не пишут. Документируется здесь, потому что живёт в том же
сервисе. Общая документация — [`SOCIAL_CONNECTOR.md`](./SOCIAL_CONNECTOR.md).

Последнее обновление: 2026-05-20.

---

## 1. Модель

- Telegram forum-группа. **Каждая задача / техвопрос = отдельная тема (topic).**
- У задачи три статуса: **📝 open** (никто не взял) → **✋ in_progress**
  (взято в работу) → **✅ done** (выполнено).
- Сотрудники создают темы, обсуждают в них, меняют статус командами.
- Бот ведёт авто-обновляемую «Доску задач» со списком открытых.

---

## 2. Команды

### Создать задачу (в любом месте группы)

| Команда | Действие |
|---|---|
| `/n <название>` или `/new <название>` | создать новую тему-задачу со статусом 📝 open; бот публикует первое сообщение |

Пример: `/n Не работает выгрузка из МойСклад`

### Внутри темы задачи

| Команда | Действие |
|---|---|
| `/t` | взять задачу в работу → ✋ in_progress |
| `/d` или `/done` | отметить выполненной → ✅ done |
| `/reopen` или `/back` | вернуть в работу → ✋ |
| `/r` или `/rename` | переименовать тему |
| `/f` или `/free` | освободить задачу (передать другому) |
| `/nnn <текст>` | внутренняя пометка |
| `/board_setup` | в отдельной теме-«доске» — опубликовать и закрепить авто-обновляемый список задач |

**Авто-reopen:** если в теме со статусом ✅ кто-то пишет сообщение — задача
автоматически возвращается в ✋ in_progress.

---

## 3. Доска задач

Отдельная тема (например «📊 Задачи в работе») + команда `/board_setup` →
бот публикует и закрепляет сообщение со списком всех открытых задач
(сгруппировано: ✋ в работе / 📝 ожидают). Сообщение **автообновляется** при
изменении статусов.

---

## 4. Где хранится

SQLite бриджа — `data/bridge.sqlite`:

| Таблица | Что |
|---|---|
| `internal_tasks` | задачи: `tg_chat_id`, `tg_topic_id`, `title`, `status` (open/in_progress/done), автор, кто взял |
| `internal_topics` | имена тем (Bot API не даёт читать имя темы — храним локально) |

Бэкап — вместе с `bridge.sqlite` через restic.

---

## 5. Правила (из встроенной справки бота)

- Не удалять чужие сообщения вручную — `/d` действует только на свои.
- Удаление чужого сообщения бот фиксирует в логе и сообщает админам.
- Решённые задачи помечать `/r ✅ название` — видно в списке тем.
