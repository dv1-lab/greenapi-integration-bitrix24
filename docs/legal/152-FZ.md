|---|---|---|

  не у нас)

## 🎯 2. Цели обработки

Все цели прямо связаны с предоставлением услуги магазина:

1. **Коммуникация с клиентом** — отправлять/получать сообщения, обрабатывать
   обращения, отвечать на вопросы о товаре.
2. **Учёт обращений** — связать переписку, заказ, звонок с одним клиентом
   (Customer-360, merge engine).
3. **Управление заказами** — оформление, доставка, гарантия, возвраты.
4. **Аналитика** — общая (без передачи третьим лицам) — какие каналы
   эффективнее, какие товары спрашивают.
5. **Защита прав** — журналы переписки (REGRESSIONS, CustomerMerge audit)
   для разбора споров.

**НЕ обрабатываем для:**
- Рекламы третьих лиц
- Профилирования с автоматическими решениями, влияющими на права субъекта
- Продажи данных

## ⏰ 3. Сроки хранения (retention)

| Категория | Retention | Где |
|---|---|---|
| Customer master record (UUID, alias) | **Бессрочно** (пока есть актуальный заказ или обращение) | Postgres `customers` |
| Customer events (сообщения, звонки) | **3 года** (срок исковой давности по ГК РФ) | ClickHouse `customer_events`, partitions по месяцам — DROP старше 36 мес |
| Тексты переписки в B24 OpenLines | **Бессрочно** в B24 (мы не контроллер retention'а Битрикс24, но они хранят) | B24 portal |
| Медиа-файлы | **30 дней** в кэше + ссылки в B24 (хранение медиа на стороне B24) | adapter `MediaCacheService` |
| Логи Caddy (access, IP) | **30 дней** | journalctl rotation |
| Логи adapter (без PII) | **7 дней** | docker logs rotation |
| Backups (БД, .env) | **7 дней (daily)** + **4 недели (weekly)** в restic Я.Диск | server backup.sh |
| `IgInboundB24Link`, `IgDirectInboundB24Link` | **Бессрочно** (для reply на старые комменты) | adapter MySQL |
| `MaxContact` cache (phone→chatId) | **Бессрочно** | adapter MySQL |

**Удаление по запросу субъекта (см. §5)** — выполняется в течение 30 дней.

Согласно ст. 6 152-ФЗ и ст. 6 GDPR:

| Marketing-рассылки (если будут) | **Отдельное согласие** — opt-in только |

## 👤 5. Права субъекта данных

Клиент имеет право (152-ФЗ ст. 14, GDPR Article 12-22):

1. **Получить копию своих данных** (Right of access):
   - Запрос на `kuznetsovd88@gmail.com`
   - Срок ответа: **30 дней**
   - Формат: машино-читаемый JSON (export из Postgres + CH по UUID)

2. **Исправить неточные данные** (Right of rectification):
   - Через оператора в любом канале → правка в B24 carga + customer-service

3. **Запрос на удаление** (Right of erasure / «право на забвение»):
   - Удаление UUID + cascade всех aliases
   - Anonymization customer_events (customer_uuid → null, имя → '<deleted>')
   - Backup retention: 4 недели (старые backup'ы НЕ исключаются — это допустимо
     согласно GDPR Recital 65, через 4 недели и они исчезнут)
   - Срок: **30 дней**

4. **Ограничить обработку** (Right to restriction):
   - Прекратить отправку сообщений и звонков → status='restricted' в Customer

5. **Возражение** (Right to object):
   - Аналогично restriction

6. **Переносимость данных** (Right of data portability — GDPR-only):
   - Export в JSON для self-hosted продолжения общения (мало вероятно для нашего use case)

**Контакт DPO** (Data Protection Officer): kuznetsovd88@gmail.com.
Так как ИП один сотрудник — DPO=Дмитрий.

## 🌐 6. Передача третьим лицам (processors)

PII клиентов передаются следующим обработчикам (подписан или будет подписан
договор поручения обработки, ст. 6 п. 3 152-ФЗ):

| Processor | Что передаём | Юрисдикция | Цель |
|---|---|---|---|
| **Bitrix24 (1С-Битрикс)** | Имя, телефон, email, переписка, история сделок | РФ | CRM, OpenLines, контактный центр |
| **Green API (ООО «Грин Эпиай»)** | Имя, телефон, переписка WhatsApp/Telegram/MAX | РФ | Транспорт мессенджеров |
| **i2crm** | Имя, IG client_id, переписка Instagram | РФ | Транспорт Instagram (через Meta Graph API) |
| **МойСклад (ООО «Логнекс»)** | Имя, телефон, email, заказы | РФ | Склад, ассортимент |
| **Novofon** | Телефон, длительность звонка, аудио-запись | РФ | Телефония |
| **Yandex (Метрика)** | ClientId (анонимизированный), URL страниц | РФ | Веб-аналитика |
| **Google reCAPTCHA** | IP, user-agent, действия на странице | США | Защита от ботов |
| **Anthropic (Claude API)** | Тексты обращений (для AI consultant / classifier) | США | AI-классификация support tickets |
| **OpenAI Whisper** (мы используем self-hosted) | Аудио звонков | self-hosted, мы контроллер | Транскрипция |

**Передача в третьи страны** (США — Anthropic, Google) — оформляется через
стандартные договорные условия (SCC) **в момент когда платформа выйдет на
сторонних клиентов** (сейчас single-tenant, наш бизнес).

**Что НЕ передаём**:
- Сторонним рекламным сетям
- Маркетплейсам (Wildberries/Ozon — мы с них ушли осенью 2025)
- Брокерам данных

## 🔐 7. Меры безопасности

Технические:
- **Шифрование at rest**: backup'ы restic (AES-256), `.env` файлы (chmod 600,
  Bitwarden master copy)
- **Шифрование in transit**: TLS 1.3 (Caddy auto-certs), SSH ed25519
- **Контроль доступа**: см. [`../SECURITY/ACCESS.md`](../SECURITY/ACCESS.md)
- **Сетевые границы**: my-server за Tailscale (private overlay), Caddy
  обратный proxy с rate-limiting (TODO P0, см. THREAT_MODEL)
- **Logging**: журналы доступа (Caddy) — 30 дней, audit log для DB
  операций (TODO P1)
- **Backup**: ежедневно 04:00 МСК на Я.Диск (restic, retention 7d/4w)

Организационные:
- **Доступ**: только Дмитрий (single point of failure — закрыто backup-person
  через Bitwarden Emergency Access, см. [`../SECURITY/ACCESS.md`](../SECURITY/ACCESS.md))
- **Регулярный аудит**: STRIDE-аудит раз в 6 мес (см. [`../SECURITY/THREAT_MODEL.md`](../SECURITY/THREAT_MODEL.md))
- **Incident response**: см. [`../RUNBOOKS/incident-response.md`](../RUNBOOKS/incident-response.md)
- **Уведомление о breach**: в течение 72 часов (GDPR Article 33) — план в RUNBOOK

## 📝 8. Уведомление об утечке (data breach)

В случае утечки PII (например, leaked .env, доступ к БД, etc.):

1. **0-2 часа**: incident response — изоляция, остановка leak'а
2. **2-24 часа**: оценка масштаба (кто-сколько-какие данные), audit log
3. **24-72 часа**:
   - **Уведомление Роскомнадзора** (152-ФЗ ст. 22.4) — через
     https://pd.rkn.gov.ru, форма уведомления
   - **Уведомление субъектов** если риск высокий (имя+телефон+переписка
     для всех 1000+ клиентов = высокий)
4. **72+ часа**: публичный disclosure если затронуты ≥1000 клиентов

Бот для контроля сроков: `@agent_dv_bot` (manual в чате tech-monitor).

См. `RUNBOOKS/secret-leak-recovery.md` для технических шагов.
